# Мастерские — бот записи на мастер-классы

Бот записывает участников на мастерские центра, ведёт резерв и посещаемость.
Источник правды — Google-таблицы: оператор и преподаватель работают в привычных
таблицах, бот синхронизирует всё остальное сам.

---

## 📋 Памятка оператору

### Где работает оператор

Оператор открывает **один файл**: «Мастерские — записи» (Google Sheets, лист «Записи»).

| Колонка | Что это | Можно трогать                  |
|---|---|--------------------------------|
| telegram_id | служебный номер участника | ❌ нет                          |
| пользователь | ник участника | ❌ нет                          |
| мастерская | номер мастерской | ❌ нет                          |
| статус | основной / резерв / отменено / отчислен | ✅ да, это главная твоя работа) |
| дата записи | когда человек записался | ❌ нет                          |

### Статусы

- **основной** — человек записан, место занято.
- **резерв** — человек в листе ожидания, место не занято.
- **отменено** — человек отменился сам (через бота).
- **отчислен** — снят организаторами (не пришёл на занятие, грубо говоря).

### Что делает оператор

**После первого занятия:**

1. Смотрит в файле посещаемости (у преподавателя), кто не пришёл.
2. В «Записях» ставит не пришедшим статус `отчислен`.
   → Бот в течение минуты: уведомит участника, уберёт его из файла посещаемости,
   освободит место.
3. Хочет поднять кого-то из резерва — меняет статус `резерв` → `основной`.
   → Бот в течение минуты: пришлёт участнику «🎉 Вы в основном списке» и перенесёт
   его в файле посещаемости (отметки преподавателя сохранятся).

**Если участник просит отписать:**

- проще всего — пусть нажмёт в боте «📋 Мои записи» → «❌ Отменить»;
- или оператор ставит статус `отменено` в таблице.

### Важные правила

1. ✅ Правки применяются примерно за 60 секунд — перезапускать ничего не нужно.
2. ❌ Не тереби первую строку (шапку) листов!
3. ❌ Не теребонькай главную таблицу «Мастерские — главная» (Профили, Мастерские,
   Форматы) — её ведут бот и Кубик.
4. ❌ Не правь файлы посещаемости вручную — их ведёт преподаватель,
   бот зеркалит состав сам, просто зачиллься.
5. ⚠️ Лучше менять статус, чем удалять строку: статус сохраняет историю.
6. ⚠️ Не создавай вторую строку для того же человека в той же мастерской.

## 🛠 Для разработчика

### Управление службой на сервере

```bash
sudo systemctl status masterskie-bot    # состояние
sudo systemctl stop masterskie-bot      # остановить
sudo systemctl start masterskie-bot     # запустить
sudo systemctl restart masterskie-bot   # перезапуск
sudo journalctl -u masterskie-bot -f    # логи в реальном времени
```

### Обновление кода

```bash
# локально
git add . && git commit -m "описание" && git push

# на сервере
cd ~/masterskie-bot && git pull && sudo systemctl restart masterskie-bot
```

### Секреты

`.env`, `service_account.json`, `oauth_*.json` **не хранятся в репозитории**
(см. `.gitignore`) и доставляются на сервер через `scp`.
